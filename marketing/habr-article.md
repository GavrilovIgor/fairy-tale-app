# Я написал ИИ-сказки для дочки, которая боялась оставаться одна. Вот что получилось

**Теги:** AI, NLP, Gemini, Next.js, детская психология, пет-проект

---

Моей дочке Тае 4 года. Полгода назад она начала панически бояться оставаться одна — когда жена выходила из комнаты, начинались слёзы и крики «не уходи». Каждый вечер одно и то же.

Я не психолог. Я разработчик. И в какой-то момент решил применить то, что умею.

## Почему именно сказка

Поискал в интернете — наткнулся на сказкотерапию. Метод, который детские психологи используют десятилетиями: ребёнок слышит историю про героя с таким же страхом, «проживает» её вместе с персонажем, и страх теряет силу. Это работает потому что страх — не логика, а эмоция. Объяснения «бояться нечего» не помогают. История — помогает.

Проблема: нормальная терапевтическая сказка требует психолога или минимум специальных знаний. Готовых «про страх разлуки с мамой для 4-летней девочки» не было.

Тогда я решил написать бота.

## Технический стек

- **Next.js 16** (App Router) — фронтенд и API routes
- **Gemini 2.5 Flash** — генерация текста сказки
- **Pollinations.ai** — бесплатная генерация иллюстраций (без API ключа)
- **Vercel** — хостинг (Hobby план, бесплатно)
- **Telegram Bot API** — Mini App

Стек выбрал простой: хотелось сделать быстро, не переусложняя. Суммарно на MVP ушло ~3 вечера.

## Как работает генерация

Пользователь вводит:
- Имя ребёнка и возраст
- Главный герой (котёнок, дракончик, зайчонок)
- Страх или проблема
- Любимые вещи
- Урок, который должна нести сказка

Промпт составлен так, чтобы получить структурированный JSON:
```
{
  title: string,
  scenes: [{ text, imagePrompt }],
  discussion: string[],  // вопросы для обсуждения с ребёнком
  anchor: { title, description }  // предмет-якорь для закрепления
}
```

Герой в сказке проходит через тот же страх что у ребёнка — и справляется. Не через «оказалось нечего бояться», а через реальное испытание и победу над ним.

Иллюстрации — Pollinations.ai. Бесплатно, без ключа, акварельный стиль. Работает медленно (~10-25 сек), но для домашнего чтения это не проблема.

## Что получилось у нас с Таей

Сделал для неё сказку — про лисёнка Рыжика, который тоже боялся что мама уйдёт и не вернётся. Лисёнок учился отпускать маму на короткое время, понимал что она всегда возвращается, и в конце радостно пошёл сам гулять с друзьями.

Читали три вечера подряд перед сном. На четвёртый — Тая сама пошла переодеваться в другую комнату. Молча. Одна.

Теперь говорит что не боится. Сама просится во двор знакомиться с детьми.

Не знаю насколько это сказка, насколько просто время. Но совпадение достаточно убедительное чтобы я решил выпустить это для других родителей.

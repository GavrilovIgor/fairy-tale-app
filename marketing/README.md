# Маркетинг — Волшебная Сказка

Скрипт для органического постинга в родительские группы Telegram.

## Требования
- Python 3.9+
- pip install telethon

## Подготовка
1. Купить виртуальный номер на smsfast.com (~30 ₽)
2. Зарегистрировать новый TG аккаунт с этим номером
3. Получить api_id и api_hash на my.telegram.org (под новым аккаунтом)
4. Заполнить .env в этой папке

## Запуск
python post.py
